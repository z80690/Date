# 外部网页材料作为需求输入的三档保真标注决策规则

## Scenario

用户需求以外部网页为背景材料（如一篇头条文章介绍某方法论的 N 个技巧），并要求基于该材料制定方案/规格。网页正文摘要可实测抓取，但关键细节（如各技巧卡片正文）嵌在头图/配图中，纯网页抓取无法取得。下游规格若直接复述"8 个技巧"的内容，极易在信息差处虚构。

## Key Signals

- 网页正文摘要与图片内嵌内容存在明确信息差：摘要只有关键词级信息（如"任务评测、指令整理、工具调用、复杂任务拆分、搭建稳定 Agent"），卡片正文细节缺失。
- 调用方在输入中明确标注"供参考，禁止虚构"——信息保真被列为硬约束。
- 头图可经图像识别部分补证（本例确认为 Anthropic 官方分享活动 "Code w/ Claude: The Prompting Playbook"），但正文级细节仍不可得。

## Essence

外部材料必须在写规格前完成三档分级，且分级结论写进规格本身：**实测可证**（可直接引用）、**未证实**（一律标注"推断"）、**不可得**（列"待补充材料清单"作为异常兜底）。信息差处的虚构风险不能靠事后审校拦截，必须在规格约束层显式封死——超出实测摘要关键词的表述不允许以确定性口吻出现。

## Approach

1. **抓取即分级**：获取外部材料时同步区分"实测抓取到的内容"与"已知存在但未取得的内容"，不要混记。
2. **图像内容尝试补取**：网页关键信息在图片中时，先尝试图像识别补取（可确认来源真实性、拿到部分关键词），但不假设能取得正文级细节。
3. **规格内写死引用边界**：规格中声明"以实测摘要关键词为准，超出部分一律标'推断'"，禁止把摘要升格为细节。
4. **不可得内容设兜底**：为正文不可得场景预设兜底动作——在产出文档中列"待补充材料清单"，把缺口变成显式待办而非隐性猜测。
5. **依据冲突走仲裁**：外部材料与项目知识库冲突时，按项目仲裁顺序裁决并留痕，不静默取舍。

## Faster Next Time

- 接到"网页 + 图片"混合材料时，先做可达性分级再动笔，避免规格写到一半才发现关键依据缺失。
- "待补充材料清单"兜底句式可直接复用，把不可得内容转化为可跟踪项。
- 在规格层封死虚构路径后，design/tasks 阶段不会再基于虚构细节扩散返工。

## Applicability Boundaries

- 适用：需求输入含外部网页/文章/图片材料；材料存在"摘要可取、细节不可得"的信息差；信息保真被列为硬约束。
- 不适用：材料可全文直接抓取（无需降级标注）；材料仅为氛围参考、不作为规格依据（无需三档分级）；内部项目文档（本身有事实源机制管保真）。

## Evidence or Examples

- 本例实证（来自会话轨迹）：头条网页《山岗上观日的期待：Claude 团队的 Prompt 实战经验，公开了》——正文摘要实测可得 5 个技巧关键词；头图经图像识别确认为 Anthropic 官方活动 "Code w/ Claude: The Prompting Playbook"；8 技巧卡片正文在图片中、网页端无法直接抓取。
- 规格落点约束（实例）："不虚构 8 技巧卡片正文（超出摘要关键词一律标'推断'）"；异常兜底设"8 技巧正文不可得 → 列待补充材料清单"。
- 调用方原始输入即标注"网页内容背景（智能体已实测抓取，供参考，禁止虚构）"，与本决策规则的分级动作一一对应。
