# 二手摘要只是线索不是依据，方案动笔前必须升级到一手原文并回标出处

## Scenario

用户要求参照某网页介绍的方法论（某团队公开的实战经验分享）制定项目优化计划。第一轮执行只基于网页摘要关键词（正文仅提供若干技巧名关键词，细节卡片不可得）动笔，被用户打回："你连那个作者的原文都没看到，你就敢给我写计划"——并明确指示"找到原文之后再给我定计划，互联网一大堆文章，用搜索引擎找"。

## Key Signals

- 打回原话直指依据等级不足：不是格式或结构问题，而是"你没读原文"。
- 上游材料只有关键词级信息（摘要/转述），无作者署名的一手来源。
- 一手原文经搜索可达：作者/机构官网文章可抓取（HTTP 200 验证），且可能有多篇与关键词对应。
- 部分细节（如分享会逐条卡片原文）多方验证不可得：视频被墙、搬运缺失、接口反爬、搜索引擎无转载。

## Essence

二手摘要只能当检索线索，不能当方案依据。制定方案前必须把事实来源升级到一手原文：搜索定位 → 抓取验证（HTTP 状态码）→ 要点提取 → 与上游关键词建立逐一对应 → 引用回标（URL+发布日期+现行状态）。原文不可得的部分要诚实三件套：如实声明不可得 + 多方验证过程留痕 + 列入待补充材料清单；自己的对应关系属推断的，逐条标注"推断"及置信依据，不伪装成原文引述。打回成本是整版作废，而先抓原文只是分钟级前置动作。

## Approach

1. **动笔前自问依据等级**："我读到的依据是几手？"摘要/转述/第三方整理一律视为线索，不直接支撑结论。
2. **搜索一手来源**：用搜索引擎定位作者或机构的官方原文（官网/官方仓库/官方文档），优先多来源交叉确认。
3. **抓取即验证**：抓取成功以 HTTP 200 为证，失败降级换渠道（主站/镜像/文档站），仍不可得则进入诚实三件套。
4. **关键词↔原文映射**：把上游摘要关键词与原文要点逐一对应，注明"对应关系属合理推断"（若原文未明说逐条对应）。
5. **引用回标**：每处引用标注 URL + 发布日期 + 现行状态（如"页面注明已迁移至 XX 现行维护"），使读者可自行溯源复核。

## Faster Next Time

- 接到"参照某网页/文章经验做方案"类派工，第一动作是找并读原文，不是写方案。
- 成本对比：先抓原文（分钟级）vs 被打回（整版作废+返工+信任损失）。
- 引用格式模板直接复用：《标题》URL（发布日期，现行状态备注）——三要素齐全才算合格引用。
- 警惕信号：方案中出现"该经验包含 N 个技巧"之类细节，但自己拿不出对应的原文出处——要么补证，要么降级为"推断"标注。

## Applicability Boundaries

- 适用：方案/计划/规格需引用外部方法论或外部经验；上游只提供摘要或转述；用户对依据真实性敏感（会亲自核查）。
- 不适用：上游已附一手原文或项目内部事实源文档（已有保真机制管着）；纯氛围参考、不进入结论的材料。
- 与相邻经验的边界：2026-11-07-external-web-material-fidelity-bounding 解决"同一网页材料内部信息差的三档标注"（动笔中的防虚构规则）；本条解决"依据等级本身不足，动笔前升级到一手原文"（前置动作）。两者互补：先定依据等级，再对材料内部做分级标注。
- 与相邻经验的边界：2026-11-07-source-tier-labeling-research 解决"引用时逐条标注信源层级（原文级/议程级/转述级）并禁止跨级冒用"（引用纪律）；本条解决"动笔前把依据升级到一手原文"（前置动作）。顺序：先升级等级，再标注层级。
