# 同类产物标记格式逐轮漂移，沿用旧正则得假 0 计数——先探测格式再两级印证

## Scenario

多轮产出同类结构化产物（考核题目/作答卷/评分 key、清单、条目型文件），每轮验收时用正则计数核对总数与分层分布（如认知层级：记忆/理解/应用）。不同轮次或不同执行方使用的行内标记格式会漂移（圆括号 → 方括号 → 粗体行），验收方若直接沿用上一轮的正则，会得到假 0。

## Key Signals

- 上一轮标记为 `（层级）` 圆括号形式，本轮变为 `【层级】` 方括号，key 文件变为 `**N.【层级】**` 粗体独立行。
- 沿用旧正则计数返回 0，疑似"产物缺题"；但人工抽读文件头尾明明条目齐全、编号连续。
- 字节数量级与上一轮相当（不支持"产物为空/大面积缺失"假设）。

## Essence

同类产物的标记格式没有显式契约时会逐轮漂移，旧正则失配产生的 0 是"正则假 0"，不是"内容缺失"。可靠的计数验证必须两级印证：**结构计数**（与标记格式无关的骨架模式，如行首题号 `^\d+[\.、]`）+ **语义计数**（按实测格式构造的层级标签模式），两者同时非零且加和一致才算通过。假 0 的第一反应是抽读文件头尾探测实际格式，不是下缺失结论。

## Approach

1. 计数前先抽读产物头尾各 10–20 行，确认本轮实际标记格式（括号形态/前缀/是否粗体/是否独立行）。
2. 结构计数：用与标记格式无关的骨架正则数总条目数，先确认"数量在"。
3. 语义计数：按实测格式构造标签正则，逐层统计分布，确认"分层对"。
4. 判定通过条件：结构计数 = 预期总数，且语义分层加和 = 结构计数，且各层均非零（若验收要求分层覆盖）。
5. 根治法：本轮若是派工方，把"条目标记格式"显式写进派工单契约（固定格式），从源头消除漂移；验收方仍按两级印证兜底，不因有契约而豁免。

## Faster Next Time

- 假 0 三步反应：换骨架正则复数 → 抽读头尾探测格式 → 重写语义正则；禁"0 = 缺失"直推。
- 把产物标记格式写进派工契约是最便宜的根治法；验收侧两级印证是不可省的兜底法。
- 计数正则选择优先级：行首结构模式 > 标签模式 > 全文模糊匹配——结构性模式漂移概率最低，适合作总数锚点。

## Applicability Boundaries

- 适用：多轮/多执行方产出的结构化文本产物计数验收（题目、清单、条目、日志行）。
- 不适用：单一执行方且有显式格式契约且历史零漂移的产物（直接按契约正则即可）；数值表格/二进制产物（结构计数不适用）。
- 边界：两级印证能证明"数量与分层齐"，不能证明"内容正确"——内容级正确性需另行抽验对照，本条不覆盖。
- 与相邻经验分工：表格事件行"已写入被误判缺失"（行拼接+截断抽查的**假缺失**）见 agent-ops/2026-11-08-event-row-append-concat-false-missing——那条管写入形态误判，本条管验收正则失配的**假 0**；同属"验证信号误导"家族，处置动作不同（前者整行重读，后者探测格式重写正则）。

## Evidence or Examples

- 同一特性连续三轮实测（出题 50 题验收）：R1 轮题目用 `（记忆）` 圆括号；V1 轮改用 `【记忆】` 方括号，首验沿用旧正则 0 命中，探测格式后改正则实测分层 15/23/12；OLD 轮亦为 `【层级】` 形式。
- V1 轮 key 文件用 `**N.【层级】**` 粗体独立行，首验 0 命中，改按粗体模式计数实测 50 题齐。
- 两次假 0 均非产物缺陷——产物本身题号连续 1–50、内容完好，实为验收正则失配。
