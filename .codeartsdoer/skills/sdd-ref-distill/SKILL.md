# SDD 参考资料查询与蒸馏（sdd-ref-distill）

## 来源指针

- 方法来源：`D:\refs\Cairn`（只读翻译，访问日期 2026-11-08）
- 提炼内容：两层知识图谱与蒸馏编排语义——README"它解决什么问题"节（全量加载贵且噪声大/向量检索丢结构→先蒸馏成结构化分层知识再按需检索子图）+ 查询端只读纪律（零 LLM 查询连接、只读不迁移）+ core/dktypes/query.go 查询语义
- 翻译原则：能力翻译为**流程方法技能**而非运行时依赖——不调用 Cairn 可执行体、不依赖其构建产物（反绑死）

## 动作序（两层）

### 第一层：查询定位（对应 Cairn 查询端"按需精准检索子图，非全量加载"）

1. 明确查询目标（goal：当前 SDD 步骤需要什么信息，一句话写清）
2. 定位候选资料：在给定来源清单中筛选与 goal 相关的文件/章节，禁全量扫描
3. 按需展开：每次至多展开 2 个命中条目，其余保留路径清单待二次查询

### 第二层：要点蒸馏（对应 Cairn 构建端"文档蒸馏成结构化分层知识：领域→子域→实体+语义关系"）

4. 抽取：从定位资料中抽取与 goal 相关的原始要点（原意保真，不改写事实）
5. 分层提炼：按"主题→要点→支撑细节"三层组织，每层可独立引用
6. 溯源指针保留：每个要点标注来源指针（文件路径+章节/行号），要点可追溯至来源

## 产出格式

| 层 | 内容 | 来源指针 |
|----|------|---------|
| 主题 | 本次蒸馏回答 goal 的一句话结论 | 来源清单 |
| 要点 | 支撑结论的分层要点（编号） | 各要点对应文件+位置 |
| 细节 | 关键原文/数据（按需附） | 精确到章节/行 |

蒸馏结果供当前 SDD 步骤产物直接引用（"被产物引用"）。

## 边界

- **只读**：对来源资料（含 D:\refs 隔离区仓库）零写操作；仓库不可读→停驻呈报，禁自行改动
- **反绑死**：不调用 cairn-mcp/cairn CLI 等外部可执行体（纯流程方法，任何环境可用）
- **溯源保真**：要点必须可在来源指针处复核，禁无出处要点（防蒸馏失真）
