name: learn-gate
description: 当接入新框架、进入新领域学习、或引用外部材料（论文/项目/文档）前触发：执行拉取修复→材料三查（质量/相关性/保真度）→学习沉淀→出题官考核→自信度≥80% 门禁全流程，学不会不干；不适用于已通过考核框架的日常复用与常规任务执行。
---
1. **拉取**：标准命令 git clone 至 refs/ 隔离目录（项目外），失败报原文错误≤3 次转降级（本地资料为依据+列未决）。
2. **材料三查**：质量（大厂背书/引用度/维护活跃度）、相关性（与当前任务匹配）、保真度（arXiv/顶会/官方文档真实出处）——评估结论落盘后才准入学习清单，禁凭记忆引用。
3. **学习沉淀**：五要素条目（链接/条目名/浓缩版四要素/正例≥1/反例≥1）经 H3 登记入知识库。
4. **考核**：独立 Worker 出题（每角度 10 题，题目与答案要点分离两文件）→ 执行代理 100% 作答 → 独立批改官判定 → 综合自信度≥80% 放行；<80% 补学重考。
5. **留痕**：考核证据链（清单/题目/key/作答/批改）落 specs 同目录，H7 刷事实表。
