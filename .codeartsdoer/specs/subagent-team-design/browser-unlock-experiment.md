# browser 解锁华为云文档实验记录（subagent-team-design T5，失败分支）

> 实验日期：2026-11-07。design 细则五：3 次尝试上限+SX 回退；**禁第三方打码、禁绕过类手段**（来源合法性红线）。最后核验：2026-11-07。

## 1. 实验设计与尝试记录

| # | 动作 | 结果 |
|---|------|------|
| 1 | browser 打开 https://support.huaweicloud.com/codeartsagent/llms.txt | 返回"Requested to open ... success"——**仅为打开请求成功，工具不返回页面内容** |
| 2 | 同上（第 2 次） | 同结果 |
| 3 | 停止（平台 Doom Loop 保护触发警告，遵从停止） | — |

## 2. 实验结论（失败分支）

**browser 内置浏览器不构成可编程抓取通道**：其定位是"在应用内为用户打开 URL"（面向人视觉），Agent 侧仅收到打开请求回执，无法读取页面内容——因此无法核验 EdgeOne 验证页是否出现、更无法抓取文档正文。**EdgeOne 拦截对 Agent 抓取路径的阻隔未解除**（curl/webfetch 层被拦截的事实不变，browser 层打开成功但内容不可达）。

## 3. 处置（design 细则五失败回退）

- **SX 语义登记**（等效落点=未决事项 U15，四字段全填）：阻塞原因=华为云文档站 EdgeOne 人机验证+browser 无内容读取能力；恢复条件=平台验证策略变化（如验证放行 Agent 会话）或用户在前端浏览器通过验证后手动提供文章清单/链接；回迁目标=spec 5.2 案例调研（community-cases.md 5 案例）；进入时间=2026-11-07。
- **呈报用户裁决**：接受降级（案例调研以本地实证+已验证文档为依据，机制完整性不受影响）或扩源（用户在前端通过验证后提供 5 篇文章链接，Agent 按七字段加工）。
- **登记选择说明**：SX 语义为状态机级阻塞；案例调研为特性内条件分支（design 细则六：⑤成功分支不阻塞④），故以未决事项 U15（四字段等效）登记而非状态机 SX——避免误伤 T6/T8 正常推进，等效且留痕。
