## ④ 两层联动细则

- **平台安全策略=硬拦截层**：拦"能不能碰"（文件访问权限、凭据扫描强制动作、告警通知）——由用户在平台界面配置，平台强制执行。
- **G3 流程检查=软检查层**：查"该不该碰"（提交清单里有没有不该进的内容、豁免语义是否如实标注）——由 Agent 在 H6 四查中执行，留痕可审计。
- 边界：互不替代——平台硬拦截不覆盖流程语义（如"豁免是否经用户明示"），G3 软检查不具强制力（如平台未配置告警时靠 Agent 自觉）。两层齐备=防御纵深。
