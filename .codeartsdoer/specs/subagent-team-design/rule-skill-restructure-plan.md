## 一、test_mini 实验结论（后端生成子智能体可行性=已实证）

1. **持久化格式**（agents/test_mini.md 实读）：`.codeartsdoer/agents/<name>.md` = YAML frontmatter + Markdown 正文提示词。frontmatter 字段：description（一句话能力）、mode（all=主/子皆可）、tools（工具白名单）、permission.skill（技能授权：默认 deny+allow 白名单）、disable（开关）、scope（project）、avatar。
2. **注册机制**：文件落盘即注册——listSkills 实证 test_mini 已挂载 5 个 project 技能（find-skills/grill-me/lazy-exec/ruleinit/skill-writer），与 skills 同机制。
3. **后端批量生成路径**：按格式写 `agents/<name>.md` → 平台自动注册 → 平台调度派工。待实测项：主智能体对注册子智能体的派工调用方式（对话 @引用或平台选择器，首次真实派工时验证）。
4. 运行时 Worker（Task 派工）与持久化子智能体（agents/*.md）双通道均已打通。
