> **红线声明**：本文件仅交付主智能体，禁止混入 questions.md，禁止向执行代理会话泄露 key 内容（spec 5.8 S1 行裁决）。
> 判分总则：逐题按"答案要点"核对覆盖度；关键要点出处均为已三查材料（M1-SDD-01 CLI 手册 / M1-SDD-02 官方最佳实践）与学习成果笔记。PASS=关键要点覆盖达标且无编造；PARTIAL=覆盖部分要点或表述不完整但无方向性错误；FAIL=关键点缺失、方向性错误、编造材料外内容。
