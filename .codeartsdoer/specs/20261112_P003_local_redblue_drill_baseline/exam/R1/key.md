## 题 2（理解｜角度① PentAGI）

**答案要点**：
- (a) 推荐路径=`DOCKER_INSIDE=true`+硬化 dind daemon over TLS；硬化要点：DOCKER_INSIDE_HOST/TLS_VERIFY/CERT_PATH/POLICY_TESTS 配置、证书只读挂载。
- (b) boot-order race：socket 未建时被 Docker 先建成目录导致 dind 卡死；blast radius：挂宿主 daemon socket=授予 agent 特权容器与 mount / 能力，PentAGI 自身也会被拿穿。
- (c) 官方把危险做法与后果写成显式反例并给硬化替代——部署清单应直接采信其推荐路径，与本单哑端点绑回环/Docker 就绪自检等约束直接对应（材料关联登记：官方文档笔记记 R1/R4，调研笔记记 R4/R9，答出"直接采信推荐路径、socket 反例禁用"即视为正确）。

**判分依据**：PASS=(a)(b)(c) 齐，(b) 两机制均说清因果；PARTIAL=推荐路径与反例结论正确但机制层面缺其一，或 (c) 泛泛而谈；FAIL=把 socket 挂载当可行路径、或推荐路径答错。
**来源指针**：`notes/学习成果-三大框架官方文档.md` §2.2/§2.3-6/§2.6；`notes/学习成果-攻防框架近三月使用调研.md` §2.3。

## 题 4（应用｜角度② 真实案例正反例）

**答案要点**：
- (a) 可检测特征（答出任两类即满足覆盖要求）：入口类=钓鱼邮件/中间人劫持（西工大）、手机短信漏洞窃凭据（授时中心）→蓝方监控邮件与凭据重置链路、TLS 会话完整性、凭据使用审计；潜伏消痕类=系统文件替换、日志篡改/消失、DLL 劫持自启动、抹文件头、清内存痕迹、杀软关闭→关键文件哈希基线对比、日志连续性/完整性校验、内存扫描、服务 DLL 校验、EDR 关闭事件告警；跳板类=多级跳板+加密回传、匿名通信节点、凌晨时段、长期低频同源连接（80 余次/数月）→非常规时段会话检测、长期低频同源连接告警、TOR/匿名代理特征流量（对齐异常外连=0 指标）。
- (b) 三类共性暴露规律（每条对应约束）：①攻击产物可见即暴露（暗链当晚被发现/僵尸账号规模涌入）→白名单与越界即停（spec 4.3.2/6.1），把活动范围关进笼子；②工具与物证全留存（本机黑客工具/云服务器会话/源代码 2 套=完整物证）→全程留痕（回执模式+三重留痕）与演练资产归档清理；③手法复用与数字指纹=串并案索引（80 个系统同一手法/软件数字指纹锁定开发者）→框架请求指纹即蓝方素材、每目标动作登记留痕、演练结束按 spec 归档。
- (c) 价值：留痕重建能力决定对抗复盘上限——攻击方主动消痕仍被还原 1100 余条链路，说明本地"三重留痕"（ARTEX traffic 全量留痕+探索图登记+T 系抓包）是把该正例能力反向用于演练复盘，保证演练全程事后可还原。

**判分依据**：PASS=(a)(b)(c) 齐：(a) 两类特征均配检测手段、(b) 三条规律各配约束、(c) 说出"留痕重建=复盘上限"层级含义；PARTIAL=特征/规律各缺一类但映射逻辑正确；FAIL=特征与手段错配、或把反例"消痕手法"当红方可模仿动作作答（违背学习目的）。
**来源指针**：`notes/学习成果-真实案例正反例.md` §1.3-1.4/§2.3-2.4/§3.4/§4.3/§5。
