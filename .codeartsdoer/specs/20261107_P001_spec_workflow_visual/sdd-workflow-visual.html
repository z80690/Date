如何查看

双击本文件 sdd-workflow-visual.html，或用 Chrome / Edge 现代版本浏览器打开（file:// 协议直开）。无需服务器、无需构建、零网络依赖，断网环境全功能可用。默认展示"流程图（SDD 步骤）"标签。

交互操作

  • 标签切换：顶部 5 标签（流程图｜时序图｜状态图｜背景资产｜使用说明），点击即时切换、无需刷新页面。
  • 节点详情：点击图中任意节点 / 泳道头 / ★门禁呈报消息 / 命名规范要素框 → 底部详情面板展开（含事实源路径）；再次点击同一节点收起；同一时刻至多一个节点展开。
  • 缩放：右上角 ＋ / − / 复位，连续缩放（50%~200%），三类图各自独立记忆缩放比例。
