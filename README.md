# 通用工作流底座（device_workflow_api）

> 需求来源：`.codeartsdoer/specs/device_workflow_api/spec.md`（v2.0，已冻结）；设计：同目录 `design.md`；任务：同目录 `tasks.md`。

## 项目一句话

通用设备/领域工作流接口层：类目统一挂载、任务下发、回执回收、能力查询；嵌入式（含小智首例）、攻防研究模拟、家电维修（仅预留接口）三类目挂载其上；自研仅接口层/适配层，底层用现成；模型只规划不直控，执行只认回执。

## 运行方式（本阶段）

- 底座：`python -m workflow_base.cli`（在 `02_软件源码` 目录下运行），全部监听 127.0.0.1（本机回环）。
- 自检：`python -m workflow_base.cli selfcheck`（四项必列 + 三项附加，逐项结论）。
- 主栈：Python 3.11，标准库优先；代码命名英文，文档中文。

## 红线（摘要）

四不红线保留（不真实入侵/不控真实肉鸡/不混真实虚拟币/不隐匿真实服务器）；目标地址白名单仅本机回环与本机局域网自建资产；外部真实目标一律拒绝并告警；攻防产出必须攻防配对；评估报告禁含最终选型（用户拍板）。
