# 注册表（抽象模板层+挂载点）

> 本文件是能力注册表的唯一登记处（tasks 2.1/2.2/5.1/5.2 落盘载体）：模板层定义契约，挂载项为具体功能实例。建立：2026-11-07。最后核验：2026-11-07。演进须经用户裁决+记变更日志。

## 一、条目六要素（缺一即登记无效）

| 要素 | 定义 |
|------|------|
| 能力描述 | 我有什么能力（具体、可判定，禁空泛） |
| 调用理由 | 为什么调用我（路由判据：什么任务场景命中） |
| 层归属 | 基础设施层/领域层/业务层/界面层 四选一 |
| 依赖 | 运行所需环境、工具、文件路径 |
| 状态 | 提案/已登记/已验证/已冻结（附原因与恢复条件）/已废弃 |
| 所有权边界 | 只读/可写范围、报告归属、禁止事项 |

## 二、四类型判据

| 类型 | 判据 |
|------|------|
| tool | 有可直接调用的原子能力入口 |
| script | 流程化可执行文件本体存在 |
| skill | .codeartsdoer/skills/<id>/SKILL.md 存在且 frontmatter 合规（name 一致+description 含触发条件） |
| agent | Router/Worker 角色或 subagent 定义文档存在 |

## 三、挂载/摘除/冻结规程

- 挂载=走五步准入（见第六节）；摘除=状态置"已废弃"（禁删行禁删文件）；冻结=临时禁用附原因与恢复条件。
- 未走完五步的功能禁入调用链；发现未登记功能被调用→立即阻断+补走五步+记违规；豁免须经用户明示并留痕；未来所有新功能场景（嵌入式开发/逆向工程/黑白攻防等）一律适用，无默认豁免。

## 四、新功能五步准入（规则第 9 条流程化）

1. **提出**：新功能提案记录（含场景与预期）。
2. **评估归类**：先查 notes/复用评估表.md=复用优先，已有可复用条目禁新建重复功能；确无覆盖再按四类型判据+四层归属判定；归类两可=停止准入呈报裁决；未查评估表=退回禁绕过。
3. **生成 SKILL**：name=动词+名词且与目录一致（禁 helper/tool1 类模糊名）；description=触发条件+适用场景+不适用场景≤1024 字；元数据不达标禁登记；script 类捆绑脚本一并交付。
4. **注册表登记**：按模板登记六要素+三问自检。
5. **H3 留痕**：索引登记+变更日志+复用评估表增量更新。
五步缺一即功能未准入。

## 六、三问自检样例（P3C 条目）

1. 我有什么能力？——对 Java 代码执行阿里 P3C 规约静态审查，输出 violation 报告（214 官方用例全绿验证）。
2. 为什么调用我？——规则第 10 条编码必审：任何编码任务写代码即触发，未过不完工。
3. 我属于哪一层？——基础设施层（审查能力底座），由 ST5 编码检查点（业务层）调用。
