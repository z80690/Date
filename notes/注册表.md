# 注册表（抽象模板层+挂载点）

> 本文件是能力注册表的唯一登记处：模板层定义契约，挂载项为具体功能实例。建立：2026-11-07。最后核验：2026-11-07。演进须经用户裁决+记变更日志（演进记录见 §七）。

## 一、条目契约（六要素+两列）

| 要素 | 定义 |
|------|------|
| 能力描述 | 我有什么能力（具体、可判定，禁空泛） |
| 调用理由 | 为什么调用我（路由判据：什么任务场景命中） |
| 层归属 | 基础设施层/领域层/业务层/界面层 四选一 |
| 依赖 | 运行所需环境、工具、文件路径 |
| 状态 | 提案/已登记/已验证/已验收/已冻结（附原因与恢复条件）/已废弃 |
| 所有权边界 | 只读/可写范围、报告归属、禁止事项 |
| **可复用性** | 直接复用/改造复用/已验收/已登记（原复用评估表职能并入，2026-11-07 裁决） |
| **缺口清单** | 当前缺口与收口状态（原复用评估表职能并入） |

> **三问自检并入说明（2026-11-07 裁决【简化重构动作 3】）**：三问自检=能力描述/调用理由/层归属三要素的问答复述，登记时自查即完成，不再独立成节；样例留存见 §六。

## 二、四类型判据

| 类型 | 判据 |
|------|------|
| tool | 有可直接调用的原子能力入口 |
| script | 流程化可执行文件本体存在 |
| skill | .codeartsdoer/skills/<id>/SKILL.md 存在且 frontmatter 合规（name 一致+description 含触发条件） |
| agent | .codeartsdoer/agents/<id>.md 存在（持久化子智能体，frontmatter 格式 test_mini/examiner 实证）或 Router/Worker 角色定义文档存在 |

## 三、挂载/摘除/冻结规程

- 挂载=走五步准入（见 §四）；摘除=状态置"已废弃"（禁删行禁删文件）；冻结=临时禁用附原因与恢复条件。
- 未走完五步的功能禁入调用链；发现未登记功能被调用→立即阻断+补走五步+记违规；豁免须经用户明示并留痕；未来所有新功能场景（嵌入式开发/逆向工程/黑白攻防等）一律适用，无默认豁免。

## 四、新功能五步准入（规则第 4 条流程化）

1. **提出**：新功能提案记录（含场景与预期）。
2. **评估归类**：查重入口=**注册表"可复用性"列**（原复用评估表职能并入，2026-11-07 裁决；查重判据完整迁入：增量更新须附新证据、同技能仅一条记录、"可复用禁新建"红线不变）→已有可复用条目禁新建重复功能；确无覆盖再按四类型判据+四层归属判定；归类两可=停止准入呈报用户裁决；未查重=退回禁绕过。
3. **生成配置**：SKILL.md 或 agents/<name>.md（name=动词+名词且与目录/文件一致；description 含触发条件+适用场景+不适用边界；元数据不达标禁登记；script 类捆绑脚本一并交付）。
4. **注册表登记**：按 §一 契约登记（六要素+可复用性/缺口清单）。
5. **H3 留痕**：知识库索引登记+变更日志记行。

## 六、三问自检样例（P3C 条目；已并入 §一 契约，样例留存备查）

1. 我有什么能力？——对 Java 代码执行阿里 P3C 规约静态审查，输出 violation 报告（214 官方用例全绿验证）。
2. 为什么调用我？——编码必审：任何编码任务写代码即触发，未过不完工。
3. 我属于哪一层？——基础设施层（审查能力底座），由 ST5 编码检查点（业务层）调用。
