# Windows 本机仿真环境启动流程（任务 4.1，嵌入式主用）

> 口径：Windows 10 + Python 3.11 本机直接启动，不强制 Linux；全程 127.0.0.1 回环；
> 不依赖真实硬件与本机自建资产之外的真实目标（spec 5.2.1 规则 1/5）。

## 一、前置条件（就绪自检对应项）

| 项 | 要求 | 自检对应 |
|----|------|---------|
| Python | 3.11+（本机 3.11.9） | 四项之一 |
| 工具链 | 标准库即可编译运行底座 | 附加项 1（工具链可编译） |
| 仿真器 | 机制验证阶段=内置本地桩；选型拍板后=Renode/QEMU（G2 门禁后引入） | 附加项 2（仿真器可加载） |
| 日志 | 04_测试验证 目录可写 | 附加项 3（日志可落盘） |

## 二、启动步骤（已验证）

1. `cd 02_软件源码`
2. 自检：`python -m workflow_base.cli selfcheck`（输出四项必列+三项附加，逐项结论；非零退出=失败）
3. 挂载三类别：`python -m workflow_base.cli mount`（嵌入式/攻防/家电占位，幂等可重复执行）
4. 机制闭环验证（注册→上线→下发→回执→状态闭环）：`python tests\verify_base.py`
   - 验证数据落盘：`04_测试验证\verify_base_2026-11-10.json`（all_pass=true 为通过）
5. 回环服务（可选）：`python -m workflow_base.cli serve --port 8765`
   - 仅绑定 127.0.0.1（4.3.6），从外部网卡地址访问不可达

## 三、协议对端与回执纪律

- 协议对端一律本机回环（127.0.0.1 Socket 或进程内桩），禁止任何真实外网连接。
- 运行数据（任务标识/回执/事件流）落盘 `04_测试验证`（带时间戳）；AI 分析结论必须引用落盘数据。
- 小智模拟器宿主的正式实现（按选型拍板结果）在 G2 门禁通过后进行（任务 6.1）；当前阶段以机制验证桩驱动闭环。
