## P19 · Kali 本地反向代理环境搭建（完成）
- 用户放弃云服务器路线（没信用卡），改用本机 WSL Kali 搭真环境练反向代理。
- 实测结论：**能搭起来**。三层验证全通（Kali 直连后端 / Kali 经 Nginx / Windows 经 Nginx 都返回 BACKEND OK）。
- 关键事实：
  - WSL NAT 模式：虚拟 IP `192.168.17.238` 从 Windows ping 不通、SSH 超时；但 `ssh kali@127.0.0.1` 免密通、sudo 免密。用户 SSH 配置没问题，地址要用 127.0.0.1。
  - Kali DNS 断（DNS 隧道不受支持），apt 装不了包。解法：Windows 下载 deb → `/mnt/c/...` 进 Kali `dpkg -i` 离线装 Nginx 1.30.4。
  - 后端 `127.0.0.1:5000` 只绑回环，从网卡 IP 访问不通 → 反向代理藏后端的效果实测成立。
  - WSL 里后台服务要用 `setsid nohup ... & disown`，普通 `&` 会被会话退出带走。
- 未做：防火墙（Kali 无 iptables/nft，WSL NAT 天然收窄暴露面，不硬装）；域名（无公网 IP）。
- 报告：`log/2026-11-18-p19-kali-reverse-proxy/报告.md`。deb 包在 `temp/nginx_debs/`。
- 服务非持久：`wsl --shutdown` 后需重跑后端启动命令（报告里有复现命令）。
