# 项目工作规则（八条 · 欧工 SOP）

> 来源：项目根目录 `AGENTS`（无扩展名）与 `CLAUDE`，2026-11-15 全文复用。
> 本文件是 WorkBuddy 侧的规则全文，运行时只读本目录（`.workbuddy/rules/`）。
> 八条正文一字不改，逐字对齐来源文件。

1. 目录池纪律：新项目开工第一步按根 README 目录池建齐目录，缺目录不得开写代码。
2. 资料归档：协议/需求 → 00；硬件资料 → 01；代码 → 02；运行数据/日志/验证记录 → 04（带时间戳）；工具与流程 → 06；参考 → 07；交付 → 08；旧版 → 09。
3. 文档同步铁律：代码变更必须同步更新 08_交付文档功能说明，不一致视为任务未完成。
4. 数据落盘铁律：运行数据必须落盘 04_测试验证 且 AI 的分析结论必须引用落盘数据，禁止凭空描述现象。
5. 就绪三自检（嵌入式开工前置）：工具链可编译 / 仿真器可加载 / 日志可落盘——任一未过不开工。
6. 回环红线：全程 127.0.0.1 本机回环，禁真实外连公网；四不红线保留（不真实入侵/不控真实肉鸡/不混真实虚拟币/不隐匿真实服务器）。
7. 回执权威：模型只规划不直控，执行结果成败只认回执，禁止猜测标记成功。
8. 门禁纪律：每阶段产出经用户确认才推进；驳回则修订重提，不越门禁。
