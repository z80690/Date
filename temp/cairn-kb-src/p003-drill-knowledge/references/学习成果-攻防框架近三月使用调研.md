  - **解读**：这是窗口内重要的定位纠偏信号——社区曾普遍期待"框架自带攻击剧本"，官方明确切割。对 P003 的直接含义：**攻击剧本与演练设计由本单 spec/design 承担，PentAGI 只提供自主执行与工具调度**——与方案 a 分工完全一致。

- **沙箱安全设计成文**（README:683-707）：DOCKER_INSIDE+硬化 dind TLS 推荐路径 vs DOCKER_SOCKET 反例（boot-order race+blast radius）。
  - **解读**：官方把"给 agent Docker 而不交出宿主"写成专节并给 Worker Node 指南（examples/guides/worker_node.md）——与本单 R4/R9（哑端点绑回环、Docker Desktop 可用性自检）直接相关，部署清单应采信其推荐路径。
- vLLM+Qwen3.5-27B-FP8 气隙指南在位（examples/guides/vllm-qwen35-27b-fp8.md）——官方认可离线部署形态；本单因无本地大模型不采用推理侧离线，但其 provider.yml 配置结构可作 custom provider 绑哑端点的参照。
