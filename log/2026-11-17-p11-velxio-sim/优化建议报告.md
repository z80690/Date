# P11 优化建议报告

## 这单发现的问题

### 1. Velxio 的 Windows 原生支持是个坑

243 个测试失败，主因全是 `pass_fds not supported on Windows`——它依赖 POSIX 文件描述符传递来起 QEMU 子进程。这在 Windows 上没解，只能走 Docker 或 WSL。建议：真要启用固件仿真层，老老实实上 Docker 镜像或 WSL Linux，别在 Windows 原生上耗。

### 2. AGPLv3 的边界要记清

Velxio 是 AGPLv3。咱只是本地跑、没改源码、没对外分发，不触发传染。但如果以后把它嵌进要分发的产品、或做成对外 SaaS，就得买商业授权。这条写进登记信息了，别到时踩坑。

### 3. 三副本一致性现在靠脚本手动跑

O2 的校验脚本做好了，但没接进 pre-commit——因为项目没有统一门禁入口，强行加 hook 会影响所有后续提交（工作区还有别人的改动）。现在靠跑 `test_rule_lens.py` 顺带校验。
