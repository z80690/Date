## 2. 机制（你问的"到底咋干活"）

- **专家**：`~/.workbuddy/plugins/marketplaces/experts/plugins/<包名>/`，里面 `.codebuddy-plugin/plugin.json` 是身份证，`agents/*.md` 是提示词正文，市场索引 `marketplace.json` 追加一条才被列出。团队型 5 个 md，单 Agent 型 1 个 md。
- **技能**：`~/.workbuddy/skills/<技能名>/SKILL.md`，YAML frontmatter 写 name + description 就会被扫到；前台"从本地添加技能"或"管理技能"挂上才显式加载。
- **连接器**：`~/.workbuddy/connectors/<用户ID>/`，走 OAuth 授权，跟前两套不是一回事。
- **加载时机**：会话启动时服务端算一张快照，把专家提示词塞进 `PluginAgentPrompt`。挂团队前后实测只动这一个槽，SOUL/记忆/规则全没变。写文件不会热更新到已开会话。
