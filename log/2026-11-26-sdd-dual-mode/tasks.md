## 2. 强制项：派工单六节字段（用户 20:50 指令，写死不许画）

**这六节不是建议，是每次 apply 派工的硬前置。少任何一节 = 派工单无效 = 禁开工。**
模板实物：`.workbuddy/templates/派工单模板.md`（1743 字节，已落盘）。

| # | 字段 | 强制内容 | 验收判据 |
|---|---|---|---|
| 1 | 基本信息 | 日期/特性名/本步产物(四选一)/模式(贴 sdd_mode_gate exit)/任务原话 | 五项全填，模式 exit 有实值 |
| 2 | 门禁命令 | 模式门禁 + 产物门禁 + CLI 语义门禁三条命令 + 各自期望 exit | 三条命令齐全，期望 exit 写明 |
| 3 | 门禁输出回执 | 每条命令真实 stdout + exit code 原样贴 | 有实输出，禁"已通过"三字占位 |
| 4 | 内容偏差人工扫 | 扫人/扫了什么(2-3条)/结论(无偏差或有偏差→退回) | 三项全填，结论二选一 |
| 5 | 产物路径 | 落盘路径 + `ls -la` 输出 | 路径在 `log/<日期>-<特性>/`，ls 输出已贴 |
| 6 | 推进判定 | 四打勾：门禁exit0 / 输出已贴 / 人工扫签收 / 产物非空 | 四勾全中才呈报，缺一停本步 |

【验证方式】：`grep -c '^## ' .workbuddy/templates/派工单模板.md` = 6（六节俱在）；任一次 apply 派工实测缺失一节 → 门禁 failure。
【证据文件】：`log/2026-11-26-sdd-dual-mode/运行时报告.md` §2.7.3。
