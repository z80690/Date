## 优化 1（最高优先级）：给"派活分类"装机器开关，救活 SDD

**问题**：SDD 靠我临场判断，今天 0 触发。
**做法**：派活时你带一个字段的标记（或写进派工单首行）：`模式: 规格 / 执行 / 快修`。
- `规格` = 必须走 sdd-spec-pipeline 或 openspec，我先出规格你确认再动手；
- `执行` = 按现有 SOP 直接干；
- `快修` = BugFix 快捷路径。
**为什么不用自动判断**：你实测过 AWS 那套数据——软提示准确率 82.5%，拦截式程序判定 100%。分类这事机器判不准，你一个字就判准了。

## 优化 2：红线检查器（exit code 可判的部分）

**问题**：六条红线是我写在 SOP 里自己读的，没有东西在我每次要跑网络命令时强制核对。
**做法**：写一个本地检查脚本（项目内，Python stdlib 就够），我在任何攻防类动作前必须先跑它：
- 输入：目标 IP/域名；
- 比对白名单文件（`box/target_whitelist.json`，只有本机地址段）；
- 命中名单外 → exit 2 拒绝，我必须停。
**已验证可行性**：11-24 演练的 `boundary_guard.py` 就是这个思路（1.2.4.8/8.8.8.8 实测被拒）。
