## 全链一图

```
用户选专家(界面) → 注入提醒行(平台) → 我读提醒+自己决定派不派(无路由)
→ TeamCreate → teams\<名>\config.json + tasks\<名>\
→ Agent(派工单全文手写) → 成员收 <teammate-message> 信封(仅此一件)
→ 成员 SendMessage → teams\<名>\inboxes\team-lead.json
→ 消息回流主会话 → 主智能体读回验收(人工) → TeamDelete 删两目录
```
