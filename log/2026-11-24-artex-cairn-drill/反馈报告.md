## 六、积分问题——这次给你查实的结论（附截图核对）

你两张图我看了：一张是模型面板（`Hy4 flash 0.00x` 打了勾，标"当前限时免费"；旁边 `快速0.15x / 均衡0.50x / 极智1.00x / Hy4 0.25x / DeepSeek-v4.1-Flash 0.11x / GLM-5.3 0.69x / GLM-5.3-Flash 0.08x / GLM-5.2 0.79x`），另一张是账户页（积分余额 **3,999**，体验版）。

你说"4000 多 → 3800 → 领 100 → 3900 多"。**这次不再瞎答，给查实的机制**（来源：官方/媒体多篇文章交叉印证）：

1. **0.00x 只免"对话模型"这一项，不是全账号免费。** 这是你"用免费模型还掉分"的最主要原因。图/文件/联网搜索/独立能力走另一套计费，不跟着 0.00x 免。你这一长会话里传过截图、干过联网搜索、调过工具——这些照扣。
2. **Auto 模式会偷换模型。** 就算你勾了限时免费位，Auto 可能按任务需要选了别的倍率模型（0.11x / 0.69x 那些）。手动锁死 0.00x 那一行才稳。
3. **免费额度用尽会自动转积分执行。** "限时免费"是限时限量的，额度跑完后继续提交就按倍率扣。
4. **每个新会话有"开机费"。** 系统提示词 + 工具定义 + 连接器清单整包发给模型，一次约 1.9万~6万 token，和任务难度无关。你这条会话从 11-17 聊到现在，中间开过不少新会话/话题，每开一次都重付一遍。

**扣的到底是什么：** 积分是算力计量（输入字数 + 输出字数 × 模型倍率），不是按次门票。你感觉"没怎么用就掉了"，是因为长会话里每次工具调用、每次联网、每张图都在算算力，不是后台有东西偷跑——8 个定时任务全 PAUSED，不会自动消耗。

**一句话结论：** 不是被盗刷，也不是后台偷跑；是"免费模型只免对话文本，其余能力照扣 + 可能 Auto 偷换 + 长会话开机费反复付"。想止住：左下角头像→订阅和用量→积分明细，看每笔挂在哪个项目（这是唯一能对账的地方，我这边没有这个接口，不编具体数字）。
